HEIC metadata remover: support status

Looking for a HEIC metadata remover for iPhone photos? This tool does not currently decode or re-encode HEIC / HEIF files. We do not accept these files, claim to clean them, or upload them to another service.

Honest format support: This tool currently supports JPEG, PNG, and WebP when your browser can decode and export the selected format. HEIC / HEIF processing is not available.

How to remove metadata from an iPhone photo

Some iPhone photos are HEIC / HEIF and cannot be processed by this tool. If you already have a JPEG or PNG copy, you can select that file here. Converting a HEIC photo to another format first may change image quality and does not, by itself, guarantee metadata has been removed.

For a HEIC file, use a conversion or metadata-removal method only if you can verify it processes the file locally and preserves the privacy you expect. Do not select sensitive photos in an online converter unless you are comfortable with its upload and retention practices.
