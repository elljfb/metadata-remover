How the tool works

Privacy and limitations

Image Metadata Remover is a static website. When you select a supported image, your browser decodes it and creates a new copy using its built-in image and canvas APIs. The selected image is not sent to an image-processing server.

What the site does and does not collect

The site code does not upload or store selected photos, set analytics cookies, or use third-party analytics, advertising, fonts, or processing libraries. The image is handled in the current browser tab and the tool does not write it to a site account or database.

Like any website, the static host receives ordinary requests to serve the page and its assets. The hosting provider may process connection data such as IP address or browser details in server logs under its own policies. This is separate from the image selected in the tool; check your host’s privacy terms for details.

Supported formats and quality

  • JPEG and WebP are re-encoded by the browser. Re-encoding can reduce image quality; the quality slider controls the requested output quality.
  • PNG output is lossless for the image pixels and preserves transparency.
  • HEIC and HEIF are not supported. They are rejected and are not uploaded or converted by this site.
  • Your browser must be able to decode and export the selected format. The tool has a 20 MB file limit and a 40-megapixel processing limit.

What metadata removal means

The tool redraws the image and exports a new file, so original camera, location, editing, and embedded preview metadata is not carried over. The browser’s encoder may add ordinary technical properties to the output, and this tool is not a forensic metadata inspector or guarantee that every non-personal file property is absent.

Metadata removal does not change identifying content visible in the image. Faces, addresses, documents, reflections, signs, and other visual details may still reveal private information. Review the image itself before sharing.

Your original file is not modified. Keep it if you need the original quality or metadata.
