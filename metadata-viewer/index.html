What this viewer can read

The viewer displays commonly used EXIF fields and detects selected XMP, IPTC, text, and color-profile blocks where they are commonly stored in JPEG, PNG, or WebP. Other fields, proprietary metadata, and some compressed text entries may not be shown. HEIC / HEIF is not supported.

For steps to check metadata with built-in device tools, see how to find metadata on a photo. Learn what EXIF data is and how it differs from metadata.
